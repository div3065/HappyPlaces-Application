# 🌟 Happy Places App

## 📌 Overview
Happy Places is a mobile application designed to help users store and manage their favorite locations. Users can add, view, and organize places with details such as images, descriptions, and locations.

## 🚀 Features
*  Add and manage favorite places
*  Attach images to locations
*  Store location details (address, coordinates)
*  Edit and delete saved places
*  User-friendly and responsive UI

## 🛠️ Tech Stack

* **Language:** Kotlin
* **Platform:** Android
* **Database:** SQLite / Room Database
* **Tools:** Android Studio, Git, GitHub



## ⚙️ Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/happy-places.git
   ```
2. Open the project in Android Studio
3. Build and run the application on an emulator or physical device


## ▶️ Usage

* Launch the app
* Add a new place with image and location
* View saved places in the list
* Edit or delete entries anytime
